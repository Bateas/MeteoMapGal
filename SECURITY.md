# Seguridad

Si encuentras una vulnerabilidad en MeteoMapGal, avísanos en privado desde la pestaña **Security** de este repositorio («Report a vulnerability»). Por favor, no abras un issue público ni la pruebes contra el servicio en producción más allá de lo necesario para mostrarla.

Cubre el código de este repositorio y la web pública que se construye con él. No hay programa de recompensas. Contestamos en cuanto podamos y te decimos qué hacemos con el aviso.

Avisos de dependencias que hemos revisado y no nos afectan, con el motivo: [`security/vex.openvex.json`](security/vex.openvex.json).

## Security (English)

Please report vulnerabilities privately through this repository's **Security** tab ("Report a vulnerability"), not in a public issue. Dependency advisories we have reviewed and found not applicable, with the reason, are in [`security/vex.openvex.json`](security/vex.openvex.json).
